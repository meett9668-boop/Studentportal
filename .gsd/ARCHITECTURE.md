## Data Flow

1. **Client Request Initiation:**
   The user navigates to an endpoint (e.g., `studenthub/student/dashboard.php`) or triggers an AJAX call via `assets/js/app.js`.
2. **Access Control & Session Validation:**
   `includes/auth.php:46` inspects `$_SESSION['user_id']` and `$_SESSION['role']`. If unauthenticated or role mismatches, the request is redirected or terminated with HTTP 403 Forbidden (`includes/auth.php:54`).
3. **Database Transaction via PDO:**
   The page calls `getDbConnection()` (`config/db.php:23`) to obtain a PDO connection. All parameterized queries execute via prepared statements (`PDO::prepare`) to prevent SQL injection.
4. **Audit Trail Logging:**
   Administrative actions and security events invoke `logAction()` (`includes/audit.php:12`), capturing user ID, action verb, timestamp, and IP address.
5. **Response Rendering:**
   The server renders HTML using standard components (`includes/header.php`, `includes/navbar.php`, `includes/footer.php`) or sends a `Content-Type: application/json` payload from the API endpoints.
